NasBuster APT repository

Packages for Raspberry Pi OS and Debian 12 or 13, on arm64 (Raspberry Pi 4 and 5) and amd64.

1. Get the signing key and check it

sudo curl -fsSL -o /usr/share/keyrings/cwnsb-archive-keyring.asc @BASE_URL@/cwnsb-archive-keyring.asc
gpg --show-keys /usr/share/keyrings/cwnsb-archive-keyring.asc

The fingerprint must read exactly:

6E4A B0CB FCC4 E45D EC76  A4B4 5282 C4BC 9717 0E72

If it differs, stop: someone may be serving a fake key. The package keeps this key up to date afterwards.

2. Add the repository

sudo tee /etc/apt/sources.list.d/cwnsb.sources >/dev/null <<'EOF'
Types: deb
URIs: @BASE_URL@
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/cwnsb-archive-keyring.asc
EOF

3. Install

sudo apt update
sudo apt install cwnsb

Then open https://<your-pi> in a browser and follow the setup.
